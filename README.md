# Agrinho2026
## Exército do Bem, controle biologico de pragas <h2>
Nesse trabalho irei retratar o assunto sobre controle biologico de pragas. Será no formato de site informacional onde terá um texto contextualizando sobre como os agricultores estão reduzindo o uso de defensivos químicos (agrotóxicos) usando a própria natureza. Mostrar que eles soltam insetos predadores (como joaninhas ou pequenas vespas) e usam fungos naturais para combater as pragas que destroem as plantações. No final do site averá um quizz sobre o tema retratado no texto.
A asistencia de IA.
